# Encoding strategies memory experiment — initial version

A PSYC 402 browser-based experiment built with **index.html**, **styles.css**, and **script.js** (no frameworks, servers, databases, or build step).

## What it does
- Randomizes the order of maintenance rehearsal, self-reference, and mental imagery and assigns one of three different six-word lists to each strategy.
- Presents 18 words for three seconds each, following instructions for each encoding strategy.
- Runs a 30-second backward-by-threes distractor task.
- Tests free recall and scores each strategy (case-insensitive, tolerant of recognizable minor typos).
- Downloads a one-row summary CSV and an 18-row word-level CSV.

## Test locally
Open `index.html` in a web browser, finish all three rounds and the counting task, enter some remembered words, and check both downloads.

## Publication
Upload the files into the root of a public GitHub repository called `encoding-demo`; enable **Settings → Pages → Deploy from a branch → main → /(root)**.
